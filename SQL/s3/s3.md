What is Amazon S3?
→ Object storage service; files/objects ko buckets mein store karta hai.
What is an S3 Bucket?
→ Bucket S3 mein objects store karne ka container hai.
What is an S3 Object?
→ File + metadata + unique key ka combination.
What is the difference between S3 and EBS?
→ S3 = object storage, EBS = block storage attached to EC2.
What are S3 Storage Classes?
→ Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier classes, etc. Different cost/access patterns ke liye.
What is S3 Versioning?
→ Same object ki multiple versions maintain karta hai; accidental deletion/overwrite se recovery mein useful.
What is S3 Bucket Policy?
→ Bucket aur objects par access permissions define karne wali JSON policy.
What is IAM vs Bucket Policy?
→ IAM users/roles ki permissions manage karta hai; bucket policy directly S3 bucket ke access ko control karti hai.
What is S3 Lifecycle Policy?
→ Objects ko automatically different storage classes mein move ya delete kar sakti hai based on rules.
Is S3 private or public by default?
→ Private by default. Access dene ke liye appropriate IAM/bucket permissions configure karni hoti hain.
