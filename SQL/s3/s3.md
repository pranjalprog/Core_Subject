# AWS S3 — Top 10 Interview Questions

## 1. What is Amazon S3?

**Answer:**
Amazon S3 (Simple Storage Service) is an **object storage service** provided by AWS. It is used to store files/objects inside **buckets**.

---

## 2. What is an S3 Bucket?

**Answer:**
An S3 Bucket is a **container used to store objects/files** in Amazon S3.

---

## 3. What is an S3 Object?

**Answer:**
An S3 Object consists of **data/file, metadata, and a unique key**.

---

## 4. What is the difference between S3 and EBS?

| S3                          | EBS                       |
| --------------------------- | ------------------------- |
| Object storage              | Block storage             |
| Used to store files/objects | Used as storage for EC2   |
| Accessed through APIs/URLs  | Attached to EC2 instances |
| Highly scalable             | Used like a disk          |

**Short answer:**
**S3 = Object Storage**
**EBS = Block Storage**

---

## 5. What are S3 Storage Classes?

**Answer:**
S3 Storage Classes are different storage options designed for different **access patterns and cost requirements**.

Examples:

* S3 Standard
* S3 Intelligent-Tiering
* S3 Standard-IA
* S3 One Zone-IA
* S3 Glacier Instant Retrieval
* S3 Glacier Flexible Retrieval
* S3 Glacier Deep Archive

---

## 6. What is S3 Versioning?

**Answer:**
S3 Versioning maintains **multiple versions of the same object**. It helps recover data from accidental **deletion or overwriting**.

---

## 7. What is an S3 Bucket Policy?

**Answer:**
An S3 Bucket Policy is a **JSON-based access policy** that defines who can access a bucket and what actions they can perform.

---

## 8. What is IAM vs Bucket Policy?

**Answer:**

**IAM:**
Used to manage permissions for **AWS users, groups, and roles**.

**Bucket Policy:**
Used to control access **directly at the S3 bucket level**.

---

## 9. What is S3 Lifecycle Policy?

**Answer:**
S3 Lifecycle Policy automatically **moves objects between storage classes or deletes objects** based on predefined rules.

**Example:**

```text
S3 Standard
     ↓
Standard-IA
     ↓
Glacier
     ↓
Delete
```

---

## 10. Is S3 Private or Public by Default?

**Answer:**
**S3 buckets are private by default.**

Access must be explicitly configured using appropriate **IAM permissions, bucket policies, or other access mechanisms**.

---

# Quick Revision

| Topic           | Key Point                         |
| --------------- | --------------------------------- |
| S3              | Object Storage                    |
| Bucket          | Container for objects             |
| Object          | File + Metadata + Key             |
| S3 vs EBS       | Object vs Block Storage           |

# Flask — Top 10 Interview Questions

## 1. What is Flask?

**Answer:** Flask is a **lightweight Python web framework** used to build web applications and REST APIs.

---

## 2. Why is Flask called a Micro Framework?

**Answer:** Flask provides the **core features** needed for web development but does not force built-in solutions for databases, authentication, etc. Extensions can be added when required.

---

## 3. How do you create a basic Flask application?

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello World"

app.run()
```

---

## 4. What is a Route in Flask?

**Answer:** A route maps a **URL to a Python function**.

```python
@app.route("/about")
def about():
    return "About Page"
```

---

## 5. What is `@app.route()`?

**Answer:** It is a **decorator** used to associate a URL with a Flask function.

```python
@app.route("/users")
def users():
    return "Users"
```

---

## 6. How do you handle GET and POST requests?

```python
from flask import request

@app.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        return "Login submitted"
    return "Login Page"
```

* **GET** → Data retrieve karna
* **POST** → Data submit/send karna

---

## 7. What is Jinja2 in Flask?

**Answer:** Jinja2 is Flask's **template engine**, used to generate dynamic HTML pages.

```html
<h1>Hello {{ name }}</h1>
```

---

## 8. What is `render_template()`?

**Answer:** It is used to **render an HTML template** from the `templates` folder.

```python
from flask import render_template

@app.route("/")
def home():
    return render_template("index.html")
```

---

## 9. What is the difference between Flask and Django?

| Flask                    | Django                      |
| ------------------------ | --------------------------- |
| Micro framework          | Full-stack framework        |
| Lightweight              | More features built-in      |
| More flexibility         | More structured             |
| Easy to start            | Steeper learning curve      |
| Good for APIs/small apps | Good for large applications |

---

## 10. How do you return JSON in Flask?

```python
from flask import jsonify

@app.route("/api")
def api():
    return jsonify({
        "name": "Rahul",
        "age": 21
    })
```

# REST API — Top 10 Interview Questions

## 1. What is a REST API?

**Answer:** REST API is an API architecture that allows applications to **communicate over HTTP** using resources such as users, products, orders, etc.

---

## 2. What is REST?

**Answer:** REST stands for **Representational State Transfer**. It is an architectural style for designing web APIs.

---

## 3. What are HTTP Methods in REST API?

| Method     | Purpose                |
| ---------- | ---------------------- |
| **GET**    | Retrieve data          |
| **POST**   | Create new data        |
| **PUT**    | Completely update data |
| **PATCH**  | Partially update data  |
| **DELETE** | Delete data            |

---

## 4. What is the difference between PUT and PATCH?

**PUT** → Complete resource ko update/replace karta hai.

**PATCH** → Resource ke **specific fields** update karta hai.

Example:

```text
PUT /users/101
PATCH /users/101
```

---

## 5. What is an API Endpoint?

**Answer:** Endpoint ek specific **URL** hota hai jiske through client API se interact karta hai.

Example:

```text
GET /api/users
GET /api/users/101
```

---

## 6. What is HTTP Status Code?

**Answer:** Status code server ke response ka **result/status** batata hai.

| Code    | Meaning               |
| ------- | --------------------- |
| **200** | OK / Success          |
| **201** | Created               |
| **400** | Bad Request           |
| **401** | Unauthorized          |
| **403** | Forbidden             |
| **404** | Not Found             |
| **500** | Internal Server Error |

---

## 7. What is JSON in REST API?

**Answer:** JSON (**JavaScript Object Notation**) ek common format hai jo client aur server ke beech **data exchange** karne ke liye use hota hai.

```json
{
  "id": 101,
  "name": "Rahul",
  "age": 21
}
```

---

## 8. What is Statelessness in REST?

**Answer:** REST API **stateless** hoti hai, matlab server har request ko independently process karta hai. Server ko previous request ka session state remember karna required nahi hota.

Example:

```text
Request 1 → GET /users/101
Request 2 → GET /users/102
```

Har request mein required information provide honi chahiye.

---

## 9. What is Authentication vs Authorization?

**Authentication** → **Who are you?**
User ki identity verify karna.

**Authorization** → **What can you access?**
User ko kya permission hai, ye check karna.

Example:

```text
Login → Authentication
Admin can delete user → Authorization
```

---

## 10. What is the difference between REST API and SOAP API?

| REST                       | SOAP                                |
| -------------------------- | ----------------------------------- |
| Architectural style        | Protocol                            |
| Lightweight                | More strict/heavy                   |
| Usually JSON               | XML commonly used                   |
| Easy to develop            | More complex                        |
| Common for web/mobile APIs | Common in enterprise/legacy systems |

---

```text
 ↓

 ↓

POST → Create
PUT → Update
PATCH → Partial Update
DELETE → Delete
 ↓
JSON
 ↓
Status Codes
 ↓

```

# OpenAI API — Top 10 Interview Questions

## 1. What is the OpenAI API?

**Answer:** OpenAI API is a platform that allows developers to integrate **AI models into their applications** using APIs.

It can be used for tasks like:

* Text generation
* Question answering
* Summarization
* Code generation
* Image/audio related AI tasks

---

## 2. How do you authenticate with the OpenAI API?

**Answer:** OpenAI API requests are authenticated using an **API key**.

The API key should be stored securely, usually in an **environment variable**, and should never be hard-coded or exposed in frontend code.

Example:

```python
from openai import OpenAI
import os

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
```

---

## 3. What is an API Key?

**Answer:** An API key is a **secret credential** used to authenticate an application when making requests to the OpenAI API.

```text
Application
     ↓
API Key
     ↓
OpenAI API
     ↓
Model
     ↓
Response
```

---

## 4. What is a Model in the OpenAI API?

**Answer:** A model is an AI model that processes the input and generates an output.

Different models can have different capabilities, speed, cost, and context limits.

Example:

```python
response = client.responses.create(
    model="MODEL_NAME",
    input="Explain REST API in simple words."
)
```

---

## 5. What is the Responses API?

**Answer:** The **Responses API** is an OpenAI API interface for generating model responses. It can be used for text generation and can also work with supported tools and other capabilities.

Example:

```python
response = client.responses.create(
    model="MODEL_NAME",
    input="What is Python?"
)

print(response.output_text)
```

---

## 6. What is a Prompt?

**Answer:** A prompt is the **input/instruction** given to the AI model.

Example:

```text
Explain database normalization with an example.
```

The model processes the prompt and generates a response.

---

## 7. What are Tokens?

**Answer:** Tokens are the units of text that AI models process.

A token can represent a word, part of a word, punctuation, or other text fragments.

Example:

```text
"Hello world"
```

is processed as tokens rather than as one indivisible string.

Tokens are important because they affect **context limits and usage/cost**.

---

## 8. What is Temperature?

**Answer:** Temperature is a generation parameter that can influence how **random or varied** the model's output is.

* Lower value → More predictable output
* Higher value → More variation

For tasks requiring consistent output, lower randomness is generally preferred.

---

## 9. How do you handle errors in the OpenAI API?

**Answer:** API calls should be wrapped with proper **error handling**.

Example:

```python
try:
    response = client.responses.create(
        model="MODEL_NAME",
        input="Hello"
    )

    print(response.output_text)

except Exception as e:
    print("API Error:", e)
```

In production applications, you should also handle issues such as authentication errors, invalid requests, rate limits, and temporary service failures appropriately.

---

## 10. How do you use OpenAI API in a Python application?

**Answer:** Install the official Python SDK, configure the API key securely, create a client, and make an API request.

```bash
pip install openai
```

```python
from openai import OpenAI
import os

client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY")
)

response = client.responses.create(
    model="MODEL_NAME",
    input="What is Flask?"
)

print(response.output_text)
```
